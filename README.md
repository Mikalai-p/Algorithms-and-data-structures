# Алгоритмы и структуры данных

Лабораторные работы и материалы по предмету "Алгоритмы и структуры данных". БГТУ, 2 курс, язык C++.

## Что внутри

- весна — лабораторные за весенний семестр
- осень — лабораторные за осенний семестр
- Презентации — лекции (.pptx) и экзаменационные вопросы (.docx)

## Про лабораторные

Небольшие консольные программы на C++ (проекты Visual Studio). Сортировки, строки, алгоритмы с возвратом, муравьиный алгоритм и другое.
